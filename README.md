# Информационные технологии

Учебный репозиторий по дисциплине «Информационные технологии».

Здесь собраны домашние задания, практические и лабораторные работы, материалы преподавателя, конспекты и учебные проекты, выполненные в течение семестра.

## Содержание репозитория

| Папка | Описание |
|---|---|
| [`Materials/`](Materials/) | Презентации, лекции и учебные материалы преподавателя |
| [`HomeWork/`](HomeWork/) | Домашние задания и отчёты |
| [`practical-work/`](practical-work/) | Практические и лабораторные работы |
| [`classwork/`](classwork/) | Задания, выполненные на занятиях |
| [`projects/`](projects/) | Учебные проекты и документация к ним |

## Учебные проекты

### GA4 Analytics Lab

Веб-проект для изучения веб-аналитики, Google Analytics 4 и отслеживания действий пользователей на сайте.

[Перейти к репозиторию проекта](https://github.com/stvxs/ga4-analytics-lab)

## Используемые технологии

- HTML
- CSS
- JavaScript
- Google Analytics 4
- Google Tag Manager
- Git и GitHub

## Цель репозитория

Систематизировать результаты обучения по дисциплине, сохранить выполненные задания и учебные материалы, а также документировать процесс разработки проектов.
