# 05. Vercel и Google Tag

Материалы по занятию «Vercel и Google Tag - Подключение GA4» в рамках дисциплины «Информационные технологии».

Рассматриваются публикация веб-проекта на платформе Vercel, работа с GitHub и VS Code, подключение Google Analytics 4 с помощью Google Tag и настройка сбора данных с сайта. Также изучаются установка тега аналитики, проверка отслеживания событий и использование UTM-меток для анализа источников трафика.
