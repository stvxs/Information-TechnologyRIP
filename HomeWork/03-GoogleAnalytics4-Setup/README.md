# 03. Google Analytics 4

Материалы по занятию «Google Analytics 4 - GA4 Setup» в рамках дисциплины «Информационные технологии».

Рассматриваются основы веб-аналитики, настройка Google Analytics 4, создание ресурса и потока данных, сбор событий, отслеживание источников трафика и анализ поведения пользователей. Также изучаются основные настройки GA4, принципы работы с отчетами и применение веб-аналитики для анализа данных проекта.
