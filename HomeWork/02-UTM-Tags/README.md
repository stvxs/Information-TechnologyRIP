# 02. UTM-метки

Материалы по занятию «UTM-метки» в рамках дисциплины «Информационные технологии».

Рассматриваются основные виды UTM-параметров, правила разметки ссылок, отслеживание источников трафика, передача данных в веб-аналитику и сохранение информации об источнике в заявках. Также описываются типичные ошибки при создании UTM-ссылок и проверка передачи параметров с помощью DevTools.
